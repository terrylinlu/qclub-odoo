## 三、显示名（BRD-001、002、003）

一个方法，后续帖子、回复、申请、接口、邮件都必须经它取显示名：

```python
board_display_name(partner, viewer_is_public)  # 返回字符串
```

| 情况 | 结果 |
|---|---|
| 访问者未登录 | `Q Club Player`（不读取姓名） |
| 已登录，姓名正常 | 姓名（`partner.name`，去首尾空格） |
| 已登录，姓名为空，或含 `@`，或数字 7 位及以上 | `Q Club Player` |

放在 `models/qclub_board.py`（普通函数，不新增或继承模型）。绝不使用 `login`、`email`、`phone`。

## 四、配置项（BRD-028，加到 `qclub.config`）
