## 二、模型

所有模型带必填的 `website_id`（AGENTS.md 第 7 节）。

### 2.1 桌台类型 `qclub.table.type`（TBL-002）

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | Char，必填 | 如"中式八球""斯诺克""九球" |
| `sequence` | Integer | 排序 |
| `active` | Boolean | 可归档 |
| `website_id` | Many2one website，必填 | |

约束：同一网站内类型名称唯一。不提供任何写死的类型；演示数据和将来的初始数据里才有具体类型。

### 2.2 桌台 `qclub.table`（TBL-001、TBL-003）

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | Char，必填 | |
| `type_id` | Many2one `qclub.table.type`，必填 | 只能选同网站的类型 |
| `hourly_price` | Monetary，必填，≥ 0 | 币种取网站所属公司的币种（AUD） |
| `currency_id` | 关联 `website_id.company_id.currency_id` | 只读 |
| `active` | Boolean | "是否启用"，停用即归档 |
| `sequence` | Integer | 排序 |
| `website_id` | Many2one website，必填 | |

约束：
- 同一网站内桌台名称唯一（数据库唯一约束 `UNIQUE(website_id, name)`，按原样比较，不忽略大小写和空格）；不同网站可以重名
- 桌台类型必须与桌台属于同一网站
- 单价不得为负

**TBL-003 的分工**：本任务提供 `qclub.table._check_bookable()`：桌台已停用时抛出明确错误。任务 1.3 建立预约模型后，在创建预约时调用它，并补一个"停用桌台不能新建预约、已有预约不受影响"的端到端测试。本任务先测这个方法本身。

### 2.3 球厅配置 `qclub.config`（CFG-001、CFG-002、CFG-004）

**每个网站一条配置记录**（`UNIQUE(website_id)`），而不是用 Odoo 的"设置"页（`res.config.settings`）。理由：设置页只有系统管理员能改，无法满足 CFG-004"球厅管理员可改、员工只读"；按网站分记录也符合 `website_id` 隔离原则。

| 字段 | 类型 | 默认值 | 校验（CFG-002） |
|---|---|---|---|
| `deposit_ratio` | Float（百分比） | 50 | 0–100 |
| `free_cancel_hours` | Integer，小时 | 24 | ≥ 0 |
| `no_show_wait_minutes` | Integer，分钟 | 30 | ≥ 0 |
| `lock_minutes` | Integer，分钟 | 10 | ≥ 0 |
| `max_consecutive_hours` | Integer，小时 | 4 | ≥ 1 |
| `max_advance_days` | Integer，天 | 14 | ≥ 0 |
| `website_id` | Many2one website，必填，唯一 | — | |

- 校验同时用 Python `@api.constrains`（给出中文提示）和数据库 `CHECK` 约束（防止绕过 ORM 写入）
- 提供 `qclub.config.get_for_website(website)`：取该网站的配置，不存在时按默认值创建。任务 1.3 起预约用它取值并做快照（CFG-003）
- CFG-005（"登录后才能查看占用"开关）属于任务 2.1，本任务不加

## 三、权限（CFG-004）

| 模型 | 球厅员工 | 球厅管理员 |
|---|---|---|
| `qclub.table.type` | 读 | 读、写、建、删 |
| `qclub.table` | 读 | 读、写、建、删 |
| `qclub.config` | 读 | 读、写、建（不能删） |

门户用户和匿名访客：本任务不开放任何权限。阶段 2 的占用接口会在服务端按需读取（任务 2.1 设计）。

按网站过滤的记录规则（SEC-003）按任务拆分在 1.5 做；本任务的模型已带 `website_id`，到时直接加规则即可。

## 四、后台菜单（ADM-001）

```
Billiards（台球厅；球厅员工可见，其他内部用户看不到）
├─ Tables              桌台：球厅员工可见（员工只读）
├─ Opening Hours       营业时间：← 任务 1.2 加入
├─ Bookings            预约：← 任务 1.3 加入
└─ Configuration       配置
   ├─ Settings         球厅配置：球厅员工可见（员工只读）
   └─ Table Types      桌台类型：仅球厅管理员可见
```

- 视图：桌台（列表可拖动排序、表单、搜索：按类型、启用状态、网站筛选）；桌台类型（列表内直接编辑）；配置（列表 + 表单，列表每行一个网站）
- **界面语言为英语**（主要面向澳洲本地客户，2026-11-05 确认）：模型名、字段名、菜单、视图、校验和报错提示都用英语原文，提示信息用 Odoo 的 `_()` 包裹，以便将来按需加中文翻译。后台菜单名示例：Billiards / Tables / Opening Hours / Bookings / Configuration / Settings / Table Types；用户组：Billiard Staff、Billiard Manager
