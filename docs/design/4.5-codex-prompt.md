## 要做的事（按设计文档的编号对应）

1. 新增结算相关字段（设计文档第 1 节）：`actual_table_fee`、`settle_reason`、`settle_operator_id`、`settle_at`、`balance_amount`、`balance_method`、`settle_correction_reason`、`settle_correction_operator_id`、`settle_correction_at`。放在新文件 `addons/qclub_billiard/models/booking_settlement.py`，用 `_inherit = 'qclub.booking'`，参照 `booking_no_show.py` 的写法：一个 `AUDIT_FIELDS` 集合，`write()` 里挡掉直接改这些字段。

2. `booking_deposit.py` 的 `deposit_state` 字段 Selection 列表里加一个新值 `('applied', 'Applied to settlement')`（设计文档第 2 节）。这是新增枚举值，不删不改现有的 `awaiting`/`paid`/`no_deposit`/`refunded`/`forfeited`/`refund_failed`，不会影响任何现有测试对这些值的断言。

3. 新增结算向导 `qclub.booking.settle`（TransientModel，新文件，比如 `addons/qclub_billiard/models/booking_settle_wizard.py`），字段和权限规则见设计文档第 3 节：`mode`（settle/correct）、`booking_id`、`actual_table_fee`、`reason`、`balance_due`（compute）、`method`。`mode == 'correct'` 的 `create()`/`write()` 权限检查照抄 `deposit_refund.py` 里对 `no_show_revert`/`extra_refund` 模式的写法（`group_billiard_manager`）。

4. `qclub_booking.py` 里把占位的
   ```python
   def action_complete(self):
       return self.write({"state": "done"})
   ```
   删掉，改成 `booking_settlement.py` 里的 `action_settle()` / `action_correct_settlement()` / `_settle()`，签名和校验逻辑见设计文档第 4 节代码块。`_settle()` 里涉及到绕开 `AUDIT_FIELDS` 的 `write()` 保护时，参照 `booking_no_show.py` 的 `_mark_no_show()` 用 `super().write({'state': ...})` 做真正的状态流转那部分写法。

5. 向导的两个确认方法 `action_confirm_settlement()` / `action_confirm_correction()`，见设计文档第 5 节。

6. 视图改动（设计文档第 6 节）：
   - `addons/qclub_billiard/views/qclub_booking_views.xml`：把 `action_complete` 按钮换成 `action_settle`（`string="Settle"`，`invisible="state != 'arrived'"`，员工权限 `group_billiard_staff`），新增 `action_correct_settlement` 按钮（`string="Correct Settlement"`，`invisible="state != 'done'"`，管理员权限 `group_billiard_manager`）。
   - 表单新增一个 "Settlement" 分组，展示 `actual_table_fee`、`balance_amount`、`balance_method`、`settle_reason`、`settle_operator_id`、`settle_at`；更正相关字段（`settle_correction_*`）只在 `settle_correction_at` 有值时显示。
   - 新增向导表单视图，参照 `deposit_payment.xml` 里 `no_show_revert_form` 的写法（一个 `qclub.deposit.refund` 的例子，这次是给 `qclub.booking.settle` 做一个类似的 `form`，字段用 `invisible="mode != 'settle'"` 之类的条件区分 settle/correct 两种模式下要不要显示 reason 必填提示文字）。
