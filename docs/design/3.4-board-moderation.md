## 一、用户看到什么

**顾客（帖子面板内）**

- 帖子和每条回复旁有 **Report**，点开选原因（Spam / Abuse / Personal information / Other），可附说明；同一内容只能举报一次，再点提示已举报
- 未登录点 Report 跳转登录，返回同一帖子
- 被隐藏的帖子：格子标记、当日列表、面板都消失（该格子恢复为普通 "Booked"），带编号的地址提示 "This post is unavailable."；被隐藏的回复显示 "This reply was removed."。My Account 同样不显示被隐藏的内容
- 被封禁的顾客可以浏览，但发帖、回复、申请、举报时提示 "Your account can't post on the board. Please contact Q Club."；预约功能不受影响

**后台（Billiards → Board）**

| 菜单 | 谁能看 | 内容 |
|---|---|---|
| Reports | 员工、管理员 | 举报队列（默认未处理）：内容原文、举报原因、举报人；按钮 **Hide and resolve**（隐藏内容并关闭举报）、**Dismiss report**（不隐藏，只关闭举报）；隐藏后按钮消失并显示 Content Hidden；列表有 Reported At 列（验收后修改，2026-11-10） |
| Posts | 员工、管理员 | 全部帖子：**Hide** / **Restore** |
| Replies | 员工、管理员 | 全部回复：**Hide** / **Restore** |
| Banned Customers | **仅管理员** | 封禁记录：顾客、网站、原因、到期时间（可空 = 永久）；员工看不到入口 |

隐藏、恢复、处理举报都记录操作人和时间。没有物理删除。举报不会自动隐藏内容。

## 二、数据模型

**`qclub.board.report`（新）**

| 字段 | 说明 |
|---|---|
| `website_id`、`reporter_id` | 网站、举报人 |
| `post_id` / `reply_id` | 二选一（数据库约束） |
| `reason` | `spam` / `abuse` / `personal_information` / `other` |
| `note` | 可选，纯文本，最多 500 字符 |
| `state` | `new` / `resolved` |
| `resolved_by`、`resolved_at` | 处理人、时间 |

**数据库部分唯一索引**：举报人 + 帖子、举报人 + 回复（BRD-020）。

**`qclub.board.ban`（新）**：`website_id`、`partner_id`、`reason`（必填）、`until`（可空）、`active`；同一网站同一顾客最多一条有效封禁。"正在封禁" = 启用且未到期，读取时判断，不依赖定时任务。

**帖子、回复新增**：`hidden`（默认否）、`hidden_by`、`hidden_at`。

## 三、频率限制（BRD-024）

在发帖、回复、申请、举报四个接口统一检查：该顾客在当前网站最近 60 秒内创建的这四类记录合计，达到 "Board Actions per Minute"（默认 5）就拒绝，并提示规定的文字，不创建记录。按已有记录统计，不新建计数表。

演示库把这个值设为 100，避免演示和 e2e 反复操作时误触发；限制本身由自动测试验证（演示验收标准第 5 条）。

## 四、权限与隔离

- 三个模型沿用既定方式：门户 / 公开用户无模型权限，只经路由；员工读举报、帖子、回复；封禁只有管理员可读写；都不可删除
- 隐藏、恢复、处理举报是专门的按钮方法，内部校验员工身份后执行，员工不能直接改内容（BRD-021）
- 记录规则按网站，**限定门户用户**
- **修复 3.2 遗留问题**：`qclub.board.post`、`qclub.board.terms` 的记录规则现在是全局规则，后台员工和管理员会受网站上下文限制，Board 菜单无法正常工作；改为限定门户用户，与其余所有模型一致
- 显示内容经 `board_display_name()` 和接口白名单；举报人姓名只在后台显示，不发给其他顾客；举报说明、封禁原因不发给前台

## 五、测试

| 规格 | 测试 |
|---|---|
| BRD-020 | 四种原因；重复举报被数据库拒绝并返回友好提示；帖子 / 回复二选一；未登录被拒；说明长度；举报他站内容被拒 |
| BRD-021 | 员工可隐藏、恢复、处理举报并记录操作人和时间；员工不能直接改内容；不能删除；举报队列默认未处理 |
| BRD-022 | 隐藏后的帖子不出现在摘要、当日列表、面板、My Account；隐藏的回复响应中不含原文；后台保留原文；恢复后重新显示 |
| BRD-023 | 管理员可封禁，员工不可；封禁后四类操作被拒、可浏览、预约不受影响；到期后恢复；他站封禁不影响本站 |
| BRD-024 | 达到上限被拒且不创建记录；四类操作合计；超过 60 秒恢复；配置值生效；不同顾客互不影响 |
| BRD-025 / 026 / 027 | 举报说明按纯文本显示；门户用户直接 ORM / RPC 被拒；缺 CSRF 被拒；AUSHARE 404；`make iso-check` 无差异 |
| e2e | 举报 → 员工在后台隐藏 → 前台显示 "This reply was removed."；管理员封禁 → 被封禁者不能回复；桌面与手机，真实点击 |
