## 四、遗留与后续

- **真机检查**：演示环境只绑定本机，真机上的预约页和留言板放到上线前在真实域名的预发布环境检查
- **网站字体自托管**：Google Fonts 连接卡住时页面脚本会延迟十几秒，上线前改为自托管（`progress.md` 第八节）
- **社区须知**：登录顾客之间能看到彼此的姓名，上线前要在须知里写明（BRD-001、002）
- **网格不实时刷新**：放到阶段 5，服务器仍保证不会重复预约
- **演示环境**：测试库为提速关闭了 `fsync`，WSL 非正常关闭后可能出现序列回退，这次手动修复，数据未丢。如果经常发生，再决定是否调整 `docker/` 配置
- **本机 e2e 依赖演示数据**：判断失败以全新环境的 CI 为准；需要全绿时先 `make demo-reset`（会清空演示数据）
- `make demo` 结束时打印的演示脚本路径仍是 `phase-1.md`；下次获准修改 `Makefile` 时一并更正
