## 三、验收过程中的反馈与处理

| # | 反馈 | 处理 |
|---|---|---|
| 1 | 营业时间看起来与实际不符（24 显示为 "00:00 (+1 day)"，分组行出现无意义的求和） | 营业时间数据本身正确；改为 12 小时制显示、去掉求和（#10） |
| 2 | 新建预约时看不到价格和押金，保存后才显示 | 选桌台即预览价格快照，服务端仍以桌台和配置为准（#9） |
| 3 | 开始时间输入框易误操作（全选、非整点） | 改为 Date + 整点下拉，默认最近可预约整点（#9） |
| 4 | Lock Expire 是否应随开始时间变化；锁定应从点击保存时起算 | 维持现规则：**点击 Save 的时刻** + 锁定时长，与开始时间无关、与打开表单的时间无关（已确认合理；演示库数据核对：Booked On 与 Lock Expire 恰好相差锁定时长） |
| 5 | 预约编号跳号（00003 后直接到 00010） | 允许跳号，不做无间隔编号（规格 H.8） |
| 6 | 预约列表需要显示"预定的时间" | 新增 Booked On 列（下单时间），与本记录同一 PR |
